# Flask HR Course Project

Информационная система кадрового учета организации на `Python + Flask`.

Проект реализует:
- публичную часть сайта предприятия;
- внутренний модуль кадрового учета (для администратора).

## Функциональность

- регистрация, вход и выход пользователей;
- разграничение прав доступа (`user` / `admin`);
- управление структурой отделов;
- управление должностями;
- учет сотрудников;
- публикация и снятие вакансий;
- административная панель управления.

## Технологии

- `Flask`
- `Flask-Login`
- `Flask-SQLAlchemy`
- `Flask-WTF`
- `Bootstrap 5`
- `SQLite`

## Структура проекта

- `app.py` - инициализация приложения, конфигурация, blueprints;
- `models.py` - ORM-модели базы данных;
- `auth.py` - регистрация и авторизация;
- `main.py` - публичные маршруты и вакансии;
- `admin*.py` - маршруты и логика административного модуля;
- `forms.py` - формы и валидация;
- `templates/` - HTML-шаблоны;
- `static/` - стили, изображения, JS;
- `tests/` - автотесты.

## Быстрый старт

1. Создать и активировать виртуальное окружение.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить приложение:

```bash
python app.py
```

Приложение доступно по адресу: `http://localhost:5555`.

## База данных

По умолчанию используется SQLite-файл: `instance/job.db`.

Сущности:
- `User` - пользователь системы;
- `Department` - отдел (с иерархией родитель/дочерний);
- `Position` - должность в отделе;
- `Employee` - сотрудник организации;
- `ActiveVacancy` - опубликованная вакансия.

### Миграция `hire_date` к типу `DATE`

Если у вас старая БД, запустите:

```bash
python migrations/20260417_employee_hire_date_to_date.py
```

Скрипт автоматически делает backup перед изменением структуры.

### Полный сброс БД (очистка данных)

```bash
python -c "from app import app; from models import db; \
with app.app_context(): db.drop_all(); db.create_all()"
```

## Тестирование

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```
