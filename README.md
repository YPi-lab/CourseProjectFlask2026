# Flask HR Course Project

Информационная система кадрового учета организации на `Python + Flask`.

Проект реализует:
- публичную часть сайта предприятия;
- внутренний модуль кадрового учета (для администратора).

## Функциональность

- регистрация, вход и выход пользователей;
- разграничение прав доступа (`user` / `admin`);
- управление структурой отделов;
- управление должностями;
- учет сотрудников;
- публикация и снятие вакансий;
- административная панель управления.

## Технологии

- `Flask`
- `Flask-Login`
- `Flask-SQLAlchemy`
- `Flask-WTF`
- `Bootstrap 5`
- `SQLite`

## Структура проекта

- `app.py` - точка входа для запуска;
- `project_app/__init__.py` - factory (`create_app`) и регистрация blueprints;
- `project_app/models.py` - ORM-модели базы данных;
- `project_app/forms.py` - формы и валидация;
- `project_app/auth/routes.py` - регистрация и авторизация;
- `project_app/main/routes.py` - публичные маршруты и вакансии;
- `project_app/admin/*` - маршруты и логика административного модуля;
- `project_app/utils/db_utils.py` - безопасные коммиты с обработкой ошибок;
- `templates/` - HTML-шаблоны;
- `static/` - стили, изображения, JS;
- `tests/` - автотесты.

## Быстрый старт

1. Создать и активировать виртуальное окружение.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить приложение:

```bash
python app.py
```

Приложение доступно по адресу: `http://localhost:5555`.

## Создание первого администратора

Создать администратора с нуля можно отдельным скриптом:

```bash
python create_admin.py --username admin --password Admin1234
```

Или без аргументов, тогда логин и пароль будут запрошены интерактивно:

```bash
python create_admin.py
```

Если пользователь с таким логином уже существует, скрипт просто назначит ему `is_admin=True` и не будет менять пароль.

## База данных

По умолчанию используется SQLite-файл: `instance/job.db`.

Сущности:
- `User` - пользователь системы;
- `Department` - отдел (с иерархией родитель/дочерний);
- `Position` - должность в отделе;
- `Employee` - сотрудник организации;
- `ActiveVacancy` - опубликованная вакансия.
